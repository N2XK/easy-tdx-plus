## 5. 未实现 / 明确不做

- Level-2 深度行情（逐笔委托、十档、撤单）——免费协议不提供。
- `.htc` 分笔记录级解码——见上。
- 扩展市场 `0x2423` 详细表格、`0x2562` 映射、`0x23f6` 附加列表——实测服务器不可用。
- CLI 的 `f10` / `fund-flow` 子命令——请用 Python API。

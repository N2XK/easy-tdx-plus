# 接口能力验证报告

> 全接口实测（2026-09-16 盘中）+ 实时能力评估。命令：标准 7709 / MAC 7709 / 扩展 7727 / 7615 F10+ICFQS。

## 一、总览

- **全接口实测：164/164 通过**（标准 + MAC + 扩展 + F10/AltF10 + ICFQS + 派生）。
- 复现：`python scripts/verify_all.py`（`--group MAC` 可分组，`--json` 输出明细）。
- **实时能力：合格**（见下）。

## 二、实时能力

| 指标 | 结果 |

结论：**实时取数达到可用水平**（毫秒级、数据实时、可并发、可限流）。

## 三、验证中发现并修复的问题

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| `get_tick_charts`（0x123E）报 `hour must be in 0..23` / 越界 | 解析规模用 `count×page_size`，实为 `total` 条紧凑排列；盘中当日含越界填充分钟 | 按 `total` 解析、按分钟回绕切分日、跳过越界分钟 |
| `get_minute_aux`（0x051b）**同连接重复调用超时** | 帧长度字段应为 `payload+2` | 长度改为 `payload+2`（重复调用稳定 15–28ms） |
| 扩展行情 `get_markets` / `get_instrument_info` 连接被关闭 | 扩展行情（7727）需**先登录**（`0x2454`） | `ExTdxClient.connect` 增加扩展登录 |
| 服务端主动推送帧导致后续请求错位 | 残留帧未清理 | `TdxConnection.execute` 发送前 `_drain_pending()` 清空缓冲区 |
| `security_list`（0x044d）**同连接重复调用超时** | 用了旧版 `0x0450` 6 字节短包、长度字段错误 | 改用 `0x044d` + `<HIII>`（market/start/count/0）、长度 `payload+2` |
| `sparkline`（0x0fd1）**同连接重复调用超时** | 该命令在单条 TCP 连接上仅响应一次 | `get_sparkline` 每次调用前重建连接（同步+异步） |
| ICFQS 龙虎榜/复盘 **HTTP 503** | 这两个入口部署在 `hot.icfqs.com`，客户端却走默认网关 | `IcfqsClient` 按入口自动选网关（hot/默认） |
| `UnifiedTdxClient.get_stock_kline` 回退返回错误周期 | `KlineCategory(int(period))` 把 `Period.MINS/DAYS` 误映射为 `MIN_3/YEAR` | 改用**显式映射表**，无对应周期时不回退 |
| 能力探测子集**覆盖**全量缓存；连接失败被持久化 | `probe_capabilities(features=…)` 直接回写快照；异常也 `save_capability` | 子集结果**合并**进快照；失败不落盘 |
| `config.json` 读-改-写竞争丢字段 | 多个 `save_*` 基于过期快照写回 | 新增 `_mutate()`，持锁完成 load→改→save |
| 官方下载断流的部分文件被当作完整文件 | `_download` 未校验字节数即 `replace` | 按 `Content-Length`/`Content-Range` 校验，不完整则保留 `.part` 供续传 |

| 本地 .day `SZ_BOND` 量系数错误 / 类型判定缺口 | 与 mootdx 表不一致 | 系数 1.0→0.01；补 18/68/58/债券 02-20 |
| 扩展市场 .day `amount` 误取成交量 | 字段赋值复制错误 | 取成交额字段（列表+DataFrame） |
| `get_fq_bars`/`get_adjust_factors` 后复权随窗口漂移 | 因子以窗口首日为基准 | 因子基于全量历史计算后裁剪窗口 |
| `0x124A get_kline_offset` 误解析 | 只读 8 字节头 | 解析 500 条分类代码表 |
| MAC 文件接口静默返回空 | 0x1215/0x1217 免费主站不可用 | 显式抛 `TdxCommandError` |
| 扩展逐笔价格未 /1000 | 与其他 ex 接口口径不一致 | 价格缩放为真实值 |
| 扩展K线 `amount` 读 `position` 字节 | 字段偏移错误 | 取第 7 字段 |

修复后全量复测：**164/164 通过**；重复调用稳定；离线单测 **390 passed**（覆盖率 65.6%）；
联网集成测试 `XMTDX_LIVE=1 pytest tests/integration/` **13 passed**（含 `Downloader` 增量下载/
覆盖度校验/缺口补拉、官方站点直连下载完整性）。

## 四、已知遗留

- 部分服务器不服务某些新命令（如个别主机对某些命令无响应）；取数命令走 `_execute_std` 自动回退全功能主机。
- L2（逐笔委托/十档）、完整历史 tick/分时：免费协议不提供。
- `0x0fd1` 的"单连接仅响应一次"是服务端行为，已由客户端重连规避（每次调用多一次 TCP 建连）。

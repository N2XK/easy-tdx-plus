# 通达信数据能力总览

> 本文汇总 easy_tdx 从**通达信**可获取的全部数据（含来源、入口、实测状态），并对照 Tushare 强项给出"已补齐 / 不可得"结论。
> 接口细节见 [`数据字典.md`](数据字典.md)，成熟度速查见 [`能力矩阵.md`](能力矩阵.md)。

## 1. 五类数据来源

| # | 来源 | 说明 |
| --- | --- | --- |
| 1 | **标准协议 7709** | `TdxClient`：代码表/K线/分时/逐笔/财务/除权/板块文件/报表下载 |
| 2 | **MAC 协议 7709** | `MacClient`：自定义字段报价、服务端复权K线、竞价、异动、chart sampling |
| 3 | **扩展市场 7727** | `ExTdxClient`/`MacExClient`：港/美/期货/期权 行情 |
| 4 | **F10 / TQLEX 7615（HTTP）** | `F10Client`（主网关）+ `AltF10Client`（tdxhub 网关）：基本面/股东/机构/题材/财务 |
| 5 | **离线 & 官方下载** | `easy_tdx.offline` + `Downloader`：vipdoc / gpcw / gbbq / zhb / downit 官方包 |

其中 `zhb.zip`（配置包，46 文件）已解析 **32 个具名 + 8 个通用兜底**；`gpcw`（季度财务）可离线批量下载 1988 至今约 **147 季**。

## 3. 对照 Tushare 强项

| Tushare 强项 | 通达信是否可补 | 说明 |
| --- | :---: | --- |

| 十大股东 / 十大流通股东 | ✅ | F10 `sdgd`/`ltgd` |
| 机构持仓 | ✅ | F10 `jgcg` + 明细/分布/对比 |
| 股东人数 / 户数 | ✅ | F10 `gdrs`（30 期） |
| 分红送股 / 增发 | ✅ | F10 + xdxr |
| 估值 / 行业排名 | ✅ | F10 + tdxhub |
| 龙虎榜 / 涨停 / 游资 / 复盘 | ✅ | ICFQS + F10 |
| 概念/行业/题材/指数成分 | ✅ | zhb + F10 + ICFQS |
| 公告 / 新闻 / 研报 | ✅ | F10 |
| 股票曾用名 | ✅ | profile.dat |
| 交易日历 / 分钟 / 逐笔 | ✅ | 自算 / vipdoc / 逐笔接口 |
| **宏观（GDP/CPI/PPI/PMI/社融/利率）** | ❌ | 通达信数据模型没有 |
| **两融 / 转融通** | ❌ | 协议端不提供 |
| **质押 / 解禁 / 回购 / 大宗** | ❌ | 不提供 |
| **ETF 申赎清单(PCF) / 可转债评级** | ❌ | 仅行情，无基本面 |
| **美股/港股财报** | ❌ | 仅行情 |

## 4. 明确不可得（含原因）

- **Level-2（逐笔委托/十档/撤单）**：免费协议不提供。
- **`.htc` 分笔记录级**：无公开规范、参考实现未完成，不发布猜测解码器（历史逐笔改走 `get_history_transaction_all`）。
- **`zhb.zip` 加密文件 `n*comte.dat`（6 个）**：私有加密（非 XOR/zlib），公开渠道无密钥 → 不可解。
- **`relation.dat` / `brkseat.dat`**：二进制/语义未知（`get_zhb_positional` 可取原始列）。
- **TQLEX 未注册入口**（`fhrz_fh`/`yjyj`）：服务器返回 `503 功能未注册`。
- **宏观 / 两融 / 质押解禁回购大宗 / ETF PCF / 港美股财报**：见上表。

## 5. 快速上手

```python
from easy_tdx import TdxClient, F10Client, AltF10Client
from easy_tdx.offline import read_financial_history_panel

# 行情 + 逐笔 + 交易日历
with TdxClient.from_best_host() as c:
    bars = c.get_bars_range(Market.SH, "600519", 20240101, 20241231, KlineCategory.DAY)
    txn = c.get_history_transaction_all(Market.SZ, "000001", 20240102)
    cal = c.get_trading_calendar(20240101)

# F10 股东 / 机构
f10 = F10Client()
top = f10.top_shareholders("600519", "20240930")
cnt = f10.shareholder_count("600519")

# 三表（tdxhub 网关）
alt = AltF10Client()
bs = alt.balance_sheet("600519")

# 历史财务面板（需先批量下载）
# c.download_financial_history("gpcw_data", 20230101, 20241231)
panel = read_financial_history_panel("gpcw_data", codes=["000001"])
```

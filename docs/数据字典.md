# easy_tdx 数据字典 / 接口总览

> 汇总各客户端可取的数据、底层命令、返回结构与关键口径。
> 4 条通道：**标准协议 7709** / **MAC 协议 7709** / **扩展市场 7727** / **7615 TQLEX（F10 + ICFQS）**，
> 另有 **离线文件** 与 **派生计算**。示例见 `examples/`，方案见 `docs/ROADMAP_补全方案.md`。

## 0. 通道与客户端

| 通道 | 客户端 | 端口/协议 | 覆盖 |
| --- | --- | --- | --- |
| 标准协议 | `TdxClient` / `AsyncTdxClient` | 7709（帧头 0x0c，cmd 0x0xxx） | 代码表、K线、分时、逐笔、除权、财务、公司资料、板块文件、报表下载、若干扩展命令 |
| MAC 协议 | `MacClient` / `AsyncMacClient` | 7709（帧头 0x1c，msg 0x12xx/0x25xx） | 行情、K线（服务端复权）、板块、资金流、竞价、异动、chart sampling |
| 扩展市场 | `ExTdxClient` / `MacExClient` | 7727 | 港股/美股/期货：列表、报价、K线、分时、逐笔、表格、服务器信息 |
| F10 | `F10Client` / `AsyncF10Client` | 7615 TQLEX (HTTP) | 公司概况、财报、题材、公告、北向、估值、涨跌停榜 |
| ICFQS | `IcfqsClient` / `AsyncIcfqsClient` | 7615 TQLEX (HTTP) | 龙虎榜、游资、每日复盘、题材/主题 |
| 离线 | `easy_tdx.offline` | 本地 .day/.lc/.dat | 日线、分钟线、板块、gbbq、历史财务 |

**命令字参考**：标准协议命令见 `commands/`；MAC 见 `mac/commands/`；扩展见 `ex/commands/`。
> 注意：部分新命令（0x0452/0x051c/0x051d/0x051a/0x053f/0x0547）帧头长度字段 = payload + 2。

## 7. 技术指标 / 工具

## 8. 单位与口径

- **价格**：协议多为 `×100`（分）+ 差分；复权价保留 2 位。
- **股本**：`get_finance_info` 的 `liutong_guben/zong_guben` 为**股**；`xdxr` 股本字段为**万股**。
- **成交量**：标准行情 `vol` 为**手**；标准 K 线 `vol` 为**股**（换手率按各自口径换算）。
- **换手率**：`vol_shares / float_shares × 100`。
- **复权**：仿射 `adjusted = mul×raw + add`（现金分红为减法），与服务端一致。
- **资金流分档**：由 L1 逐笔按单笔金额分档，不等同官方口径。

## 9. 已知限制

- **Level-2（逐笔委托/十档/撤单）**、完整历史 tick / 历史分时：免费协议不提供。
- 部分新命令仅在部分服务器可用；取数命令走 `_execute_std` 自动回退全功能主机。
- 扩展市场 `0x2423` 详细表格、`0x2562` 映射、`0x23f6` 附加列表：实测不可用，未实现。
- `get_stock_profile` 每只股票一次财务请求（无批量财务命令）。

# easy_tdx 数据字典 / 接口总览

> 汇总各客户端可取的数据、底层命令、返回结构与关键口径。
> 4 条通道：**标准协议 7709** / **MAC 协议 7709** / **扩展市场 7727** / **7615 TQLEX（F10 + ICFQS）**，
> 另有 **离线文件** 与 **派生计算**。示例见 `examples/`，方案见 `docs/ROADMAP_补全方案.md`。

## 0. 通道与客户端

| 通道 | 客户端 | 端口/协议 | 覆盖 |
| --- | --- | --- | --- |
| 标准协议 | `TdxClient` / `AsyncTdxClient` | 7709（帧头 0x0c，cmd 0x0xxx） | 代码表、K线、分时、逐笔、除权、财务、公司资料、板块文件、报表下载、若干扩展命令 |
| MAC 协议 | `MacClient` / `AsyncMacClient` | 7709（帧头 0x1c，msg 0x12xx/0x25xx） | 行情、K线（服务端复权）、板块、资金流、竞价、异动、chart sampling |
| 扩展市场 | `ExTdxClient` / `MacExClient` | 7727 | 港股/美股/期货：列表、报价、K线、分时、逐笔、表格、服务器信息 |
| F10 | `F10Client` / `AsyncF10Client` | 7615 TQLEX (HTTP) | 公司概况、财报、题材、公告、北向、估值、涨跌停榜 |
| ICFQS | `IcfqsClient` / `AsyncIcfqsClient` | 7615 TQLEX (HTTP) | 龙虎榜、游资、每日复盘、题材/主题 |
| 离线 | `easy_tdx.offline` | 本地 .day/.lc/.dat | 日线、分钟线、板块、gbbq、历史财务 |

**命令字参考**：标准协议命令见 `commands/`；MAC 见 `mac/commands/`；扩展见 `ex/commands/`。
> 注意：部分新命令（0x0452/0x051c/0x051d/0x051a/0x053f/0x0547）帧头长度字段 = payload + 2。

**服务器能力探测与选路**：不同服务器支持的命令不同。`TdxClient.probe_capabilities(host)` / `get_capabilities()` 返回分项能力
（`quotes/kline/transaction/finance/xdxr/security_list`，缓存 1h 并持久化到 config.json）。
`TdxClient.from_best_host(require=[...])` 会直接在低延迟主机中选第一台**支持全部所需能力**的，避免"先失败再回退"。

> 官方通道（`downit5.cfg`）：`2ktic`(已下线)、`g3tic`/`g4tic`(分笔，单日~80MB)、`g3day`/`newday`/`g4day`(日线)、`dbf/{info,base,gbbq}.zip`、`vipdoc.zip`；`download_named('gbbq.zip')` 可得权威 gbbq。
> `.htc` 记录级解码**未实现**。已确认容器帧与每标的 30B 头，且头内 `count` 字段 = 当日该股逐笔数（实测 000001/20240102 = 4513，与在线逐笔一致）；但解压块为**多数组、私有变长差分编码**（非标准 price 变长、非定长 16B、非 XOR、非嵌套 zlib；字节分布集中于 0x80 段），无公开规范、社区参考实现亦未完成（`datochan/ParseTicFile` 自注"都还没解析"）。故**不发布猜测性解码器**。

> **获取历史逐笔的推荐途径**：`get_history_transaction_all(market, code, date)`（自动分页），实测服务器可回溯多年（如 2024-01-02 完整 4513 笔），无需解析 80MB 的 `.htc`。


> 解析采用 numpy 结构化数组向量化；`*_df` 为最快路径。

## 7. 技术指标 / 工具

**技术指标**（`easy_tdx` 顶层）：`ma` / `ema` / `macd` / `kdj` / `boll` / `rsi` / `volume_ratio` /
`add_indicators(bars, ...)`。口径：MACD 柱=2×(DIF−DEA)，K/D/RSI 用 SMA(x,n,1)，BOLL 用估算（样本）标准差；公式解释器 STD/VAR 为样本口径，STDP/VARP 为总体口径。

**公式解释器**：`evaluate(formula, bars)` / `TdxClient.get_formula(market, code, formula, ...)`，
支持 `+ - * /`、比较、AND/OR/NOT、变量赋值 `:`/`:=`，以及函数：
REF/MA/EMA/SMA/SUM/HHV/LLV/STD/COUNT/CROSS/ABS/MAX/MIN/IF/RSI/BARSLAST/
BARSLASTCOUNT/BARSCOUNT/HHVBARS/LLVBARS/BACKSET/SUMBARS/FILTER(TFILTER)/
UPNDAY/DOWNNDAY/SLOPE/VAR/DMA/CONST/SQRT/POW/LOG/LN/EXP/SIGN/MOD/INTPART/
ROUND/BETWEEN/ZIG/PEAK/TROUGH/PEAKBARS/TROUGHBARS/TR/ATR/OBV/PDI/MDI/ADX/ADXR/SAR/
WMA/MTM/ROC/DPO，别名 IFF/AVERAGE/STDDEV。
复合指标可用公式表达并与 `derive` 指标口径一致（MACD/BOLL 逐步一致，KDJ 收敛一致）。
无参指标函数（OBV/TR/ATR，及 PDI/MDI/ADX/ADXR/SAR）自动读取 HIGH/LOW/CLOSE/VOL。

**工具**：

## 8. 单位与口径

- **价格**：协议多为 `×100`（分）+ 差分；复权价保留 2 位。
- **股本**：`get_finance_info` 的 `liutong_guben/zong_guben` 为**股**；`xdxr` 股本字段为**万股**。
- **成交量**：标准行情 `vol` 为**手**；标准 K 线 `vol` 为**股**（换手率按各自口径换算）。
- **换手率**：`vol_shares / float_shares × 100`。
- **复权**：仿射 `adjusted = mul×raw + add`（现金分红为减法），与服务端一致。
- **资金流分档**：由 L1 逐笔按单笔金额分档，不等同官方口径。

## 9. 已知限制

- **Level-2（逐笔委托/十档/撤单）**、完整历史 tick / 历史分时：免费协议不提供。
- 部分新命令仅在部分服务器可用；取数命令走 `_execute_std` 自动回退全功能主机。
- 扩展市场 `0x2423` 详细表格、`0x2562` 映射、`0x23f6` 附加列表：实测不可用，未实现。
- `get_stock_profile` 每只股票一次财务请求（无批量财务命令）。
